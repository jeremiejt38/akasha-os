# v0.25.0 — Akasha Aura : posters et rangées horizontales (polish visuel)

> Amélioration visuelle de l'onglet **Divertissement** : remplace les rangées de titres texte par
> de vraies rangées de posters Plex, façon Fire TV/Plex natif, avec navigation horizontale.

## Ce qui est livré

- **`Aura.xml`** : les 4 paires de labels (titre + texte concaténé) sont remplacées par 3 rangées
  `<control type="list" orientation="horizontal">` affichant les posters (`ListItem.Art(thumb)`,
  déjà résolus avec le `X-Plex-Token` par `plex_client.py`) et le titre en dessous. Une bordure
  colorée (`FF6C8CFF`) apparaît autour de la tuile focalisée.
- **`aura_window.py`** : `_render_divertissement_rows` peuple chaque `ControlList` via
  `xbmcgui.ListItem` + `setArt({'thumb': ...})` au lieu de concaténer les titres dans un label.
  Ajout de `_on_row_item_selected` qui affiche une notification avec le titre de l'item sélectionné
  (la délégation de lecture reste à trancher, voir `docs/aura/decisions.md`).
- Réduction de 4 à **3 rangées visibles** pour que les posters tiennent confortablement dans
  1080p (les rangées supplémentaires générées par `plex_client.entertainment_rows()` existent
  toujours côté données, seules les 3 premières sont affichées).
- Navigation : `Down` depuis l'onglet Divertissement entre directement dans la première rangée ;
  `Up`/`Down` circule entre les 3 rangées ; `Left`/`Right` navigue horizontalement dans une
  rangée (géré nativement par le contrôle `list`) ; `Back` remonte d'abord vers la barre d'onglets,
  puis ferme Aura (filet de sécurité natif Kodi toujours actif).

## Validation réelle

Validée le 2026-08-18 via PixelCamera + `kodi-send` sur le Pi (`192.168.1.88`), en v0.25.0 :

- Les 3 rangées ("Continuer à regarder", "Ajoutés récemment", "Dessins Animées — Sortis
  récemment") s'affichent avec de vrais posters Plex (couvertures de films/séries reconnaissables).
- Navigation `Right` x3 : la sélection se déplace correctement de tuile en tuile avec la bordure de
  focus visible.
- Navigation `Down` x2 : passage rangée 1 → rangée 2 → rangée 3 confirmé visuellement.
- `Select` sur un item : déclenche `onClick` sans erreur (notification affichée, non capturée sur
  les captures d'écran en raison du délai, mais aucune exception dans les logs Kodi).
- `Back` : remonte à la barre d'onglets puis ferme Aura au second appui, révélant l'accueil natif
  Kodi (Akasha) — comportement de filet de sécurité préservé.

## Notes

- La lecture effective d'un item sélectionné n'est pas encore implémentée (affiche seulement une
  notification avec le titre) ; le mécanisme de lecture (délégation PM4K vs résolution directe du
  flux Plex) reste à trancher, voir `docs/aura/decisions.md`.
- Seules 3 rangées sur le total généré par `entertainment_rows()` sont affichées pour des raisons
  d'espace écran ; envisager un défilement vertical de la page si plus de rangées doivent être
  visibles à l'avenir.
