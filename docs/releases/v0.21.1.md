# v0.21.1 — Akasha Aura, jalon 3 : bibliothèque complète (recherche, tri, genre)

> Jalon 3 de la roadmap `docs/aura/roadmap.md` : ajouter une **vue bibliothèque complète** pour les
> sections vidéo, avec recherche, tri et filtre par genre. Cette release inclut le fix de navigation
> entre la liste et la barre d'outils.

## Ce qui est livré

- **`resources/lib/plex_client.py`** : ajout de `video_sections()`, `section_items()` (tri par
  paramètre `sort`) et `search()` pour alimenter la bibliothèque.
- **`resources/lib/aura_library.py`** : nouvelle `WindowXMLDialog` `AuraLibraryWindow` qui :
  - charge la première section de type `movie` trouvée dans le serveur Plex ;
  - affiche jusqu'à 200 items dans un `list` vertical ;
  - propose un bouton **Rechercher** (clavier virtuel Kodi + filtrage côté API) ;
  - propose un bouton **Trier** (Titre, Date de sortie, Date d'ajout, Note) ;
  - propose un bouton **Genre** (liste des genres de la section + option "Tous").
- **`resources/skins/Default/1080i/AuraLibrary.xml`** : interface de la bibliothèque (header,
  barre d'outils, liste, bouton Retour).
- **`resources/skins/Default/1080i/Aura.xml`** + **`resources/lib/aura_window.py`** : bouton
  **Bibliothèque** dans le bandeau d'onglets pour ouvrir la vue.
- **`tests/test_plex_client.py`** : tests pour les nouvelles méthodes du client.

## Validation réelle

Validation effectuée le 2026-08-18 via PixelCamera (`http://localhost:8088/frame.jpg`) +
`kodi-send` sur le Pi (`192.168.1.88`) :

- Déploiement v0.21.0 puis v0.21.1 → le marqueur de version affiche `0.21.1`.
- Aura s'ouvre automatiquement, les rangées s'affichent.
- Navigation `Right` jusqu'au bouton **Bibliothèque**, `Select` → la fenêtre
  `AuraLibrary.xml` s'ouvre.
- La première section `movie` est "Dessins Animés" : **771 résultats** affichés, triés par titre.
- Navigation `Up` depuis la liste vers la barre d'outils opérationnelle après le fix v0.21.1.
- Bouton **Rechercher** déclenche le clavier virtuel (visible dans le log par le chargement de
  `DialogKeyboard.xml`).
- Bouton **Retour** / action `Back` ferme la bibliothèque et revient à Aura.

## Notes

- L'affichage reste texte seul (titres) ; les posters/miniatures et les listes horizontales visuelles
  arriveront dans les jalons suivants si nécessaire.
- La section affichée est la première section `movie` trouvée. Le choix de section peut être ajouté
  plus tard.
- Prochain jalon : `Jeux` (tuiles Steam Link / Moonlight / Cloud Gaming) ou amélioration visuelle de
  l'onglet App.
