# v0.19.0 — Akasha Aura, jalon 2 : rangées Divertissement via l'API Plex

> Jalon 2 de la roadmap `docs/aura/roadmap.md` : alimenter l'onglet **Divertissement** par appels
> directs à l'API Plex (`X-Plex-Token`), en remplacement du placeholder du jalon 1.

## Ce qui est livré

- **`resources/lib/plex_client.py`** : client JSON pur (sans dépendance `xbmc*`), testable avec
  `python3 -m unittest`. Endpoints utilisés :
  - `/library/onDeck` → **Continuer à regarder**
  - `/library/recentlyAdded` → **Ajoutés récemment**
  - `/library/sections` → liste des sections de films
  - `/library/sections/{key}/all?sort=originallyAvailableAt:desc` → **Sortis récemment**
  - `/library/sections/{key}/genre` + `/library/sections/{key}/all?genre={genre}` → **rangées par genre**
- **`resources/lib/aura_window.py`** : au `onInit`, si `plex.server_url` + `plex.token` sont
  configurés dans les réglages de l'addon, charge les rangées et met à jour les labels de
  l'onglet Divertissement.
- **`resources/skins/Default/1080i/Aura.xml`** : remplace le placeholder du jalon 1 par 4 paires de
  labels (titre de rangée + titres des items), id `3010`/`3020` à `3013`/`3023`.
- **`tests/test_plex_client.py`** : tests unitaires avec réponses HTTP mockées (`urllib.request.urlopen`).

## Configuration attendue sur le device

Les réglages `plex.server_url` (défaut `http://192.168.100.133:32400`) et `plex.token` doivent être
renseignés dans :

```
/storage/.kodi/userdata/addon_data/script.akasha.aura/settings.xml
```

ou via l'écran de configuration de l'addon dans Kodi. Le token **X-Plex-Token** n'est pas commité
dans le dépôt (conformément à `AGENTS.md` et `docs/aura/spec.md`).

## Validation réelle

Validation effectuée le 2026-08-18 après rétablissement du Pi en Ethernet direct sur la box
(`192.168.1.88`) :

1. Déploiement `./scripts/apply.sh 192.168.1.88 Jt85948594` → `0.19.0` confirmé par `Akasha Splash`
   (`local=0.19.0, remote=0.19.0`) et par le menu contextuel natif patché en `Akasha OS 0.19.0`.
2. Configuration `plex.server_url` + `plex.token` copiée depuis `script.plexmod/settings.xml` du Pi
   vers `script.akasha.aura/settings.xml` (jamais commitée).
3. Redémarrage Kodi.
4. Depuis le poste Devin, via PixelCamera (`http://localhost:8088/frame`) + `kodi-send` :
   - Akasha Aura s'ouvre automatiquement après l'intro.
   - Onglet **Divertissement** affiche les rangées Plex (Continuer à regarder, Ajoutés récemment,
     Films — Sortis récemment, Documentaires — Sortis récemment, etc.).
   - Navigation `Right` fonctionnelle : Divertissement → Jeux → App.
   - `Back` révèle l'accueil natif Kodi en dessous.
5. Accès réseau : le serveur local (`192.168.100.133:32400`) n'est pas routable depuis le réseau
   `192.168.1.x` ; l'URL Plex utilisée est donc le `plex.direct` public (`https://92-157-...plex.direct:32400`)
   avec le token. L'appel API fonctionne et retourne du JSON valide.

## Notes et points restants

- L'affichage actuel est **texte seul** (titres de rangées + titres des items concaténés). Les
  prochains jalons pourront ajouter les posters/miniatures et des listes horizontales navigables.
- Le token et l'URL Plex restent dans `settings.xml` du device, hors dépôt. Si l'IP publique change,
  il faudra mettre à jour `plex.server_url`.
