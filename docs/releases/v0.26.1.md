# v0.26.0 → v0.26.1 — Akasha Aura : icônes d'onglets et sous-onglets par onglet

> Jalon 7 (au-delà de la spec initiale) : remplace les libellés texte des 3 onglets principaux par
> des icônes, et ajoute les sous-onglets prévus pour chacun (Divertissement, Jeux, App).

## Ce qui est livré

### Icônes des 3 onglets principaux

- Icônes générées (PNG, silhouette blanche sur fond transparent, teintables via `colordiffuse`
  comme le reste du skin) : lecture (Divertissement), manette (Jeux), grille d'applications
  (App). Fichiers dans `resources/skins/Default/media/tab-*.png`.

### Divertissement — un sous-onglet par bibliothèque Plex

- Remplace les 3 rangées fixes (Continuer à regarder / Ajoutés récemment / Sortis récemment) par
  une barre de sous-onglets dynamique : un bouton par section vidéo Plex (jusqu'à 9), alimentée en
  direct via `plex_client.video_sections()`.
- Chaque sous-onglet affiche une grille de posters (triée par date d'ajout) de la bibliothèque
  correspondante.
- **Navigateur Saisons → Épisodes** (`aura_show.py` + `AuraShow.xml`) : pour les bibliothèques de
  type série, sélectionner un item ouvre un navigateur dédié (Saisons, puis Épisodes d'une saison),
  via les nouvelles méthodes `plex_client.show_seasons()` / `season_episodes()`.
- Le bouton "Bibliothèque" (recherche/tri/genre) reste disponible séparément.

### Jeux — SteamLink / Moonlight / Autres

- **SteamLink** : bibliothèque de jeux Steam avec jaquettes, triée par défaut du dernier joué au
  plus ancien, via l'API Web Steam (`steam_client.py`, pur, testé). Chaque utilisateur Akasha
  configure sa propre clé API + SteamID64 (réglages `steam.api_key` / `steam.steam_id`) — prompt
  clavier intégré à la première ouverture si non configuré.
- **Moonlight** : bibliothèque d'applications configurées sur l'hôte Sunshine associé
  (`sunshine_client.py`, pur, testé), via l'API REST `/api/apps` de Sunshine (LizardByte),
  authentification basique. Réglages `sunshine.server_url` / `username` / `password`, même
  mécanisme de prompt clavier au premier accès.
- **Autres** : grille de tuiles existante (`games.DATA.xml`), désormais limitée aux applications
  hors Steam Link/Moonlight (ex. Cloud Gaming), puisque ces deux-là ont leur propre sous-onglet.

### App — Mes Apps / Store

- Remplace le bouton unique "Gerer les applications" par deux sous-onglets : **Mes Apps** (ouvre
  l'inventaire complet, `AuraApp.xml`) et **Store** (ouvre l'Akasha Store, `AuraStore.xml`)
  directement, sans passer par un bouton intermédiaire.

## Découvertes techniques pendant la validation

- **Sunshine `/api/apps`** : fonctionne avec authentification basique (login/mot de passe admin
  définis via `sunshine.exe --creds`), mais l'endpoint `/api/covers/{index}` documenté n'est pas
  disponible sur toutes les versions de Sunshine — les jaquettes ne s'affichent donc que si
  `image-path` est une URL absolue `http(s)://` dans la config Sunshine (comportement documenté et
  testé, pas un bug).
- **Steam Web API** : fonctionne immédiatement avec une clé API + SteamID64, jaquettes via
  `cdn.cloudflare.steamstatic.com/steam/apps/{appid}/library_600x900.jpg`.
- Ni SteamLink ni Moonlight n'exposent nativement une "bibliothèque" — ce sont des clients de
  streaming. Lancer un jeu précis depuis Aura n'est donc pas fiable/scriptable : la sélection d'un
  item ouvre le client de streaming général (`RunAddon`) avec une notification du titre visé,
  cohérent avec le comportement déjà en place pour Divertissement/App.

## Validation réelle

Validée le 2026-08-18 via PixelCamera + `kodi-send` sur le Pi (`192.168.1.88`), en v0.26.0/v0.26.1 :

- Icônes des 3 onglets visibles et lisibles.
- 9 sous-onglets Divertissement fonctionnels (Dessins Animées 771 items, Films 4857 items,
  Séries TV 419 items, etc.), navigation Saisons → Épisodes testée sur "Daredevil : Born Again"
  (2 saisons, épisodes avec vraies vignettes).
- SteamLink : 60 jeux Steam réels affichés avec jaquettes, triés par dernier joué (Green Hell,
  Phasmophobia, Battlefield 6...), correspond exactement à l'ordre retourné par l'API Steam testée
  en direct.
- Moonlight : erreur de chargement affichée proprement (le Pi ne peut pas joindre `nzxt` sur le LAN
  `192.168.1.100` — "No route to host" — malgré la documentation indiquant le même réseau ; l'API
  Sunshine elle-même a été validée en direct via l'adresse VPN `10.20.0.4`). **Problème réseau,
  pas un bug du code** — voir note ci-dessous.
- Autres : tuile "Cloud Gaming" seule, Steam Link/Moonlight bien exclus.
- App : sous-onglets "Mes Apps"/"Store" fonctionnels, ouverture directe des fenêtres existantes.
- Correctif v0.26.1 : alignement centré des libellés de sous-onglets (le libellé "Emissions TV"
  débordait visuellement des boutons de 195px de large sans `align`/`aligny`).

## Point réseau à signaler (hors code Aura)

Le Raspberry Pi (`192.168.1.88`) ne parvient pas à joindre `nzxt` sur son IP LAN documentée
(`192.168.1.100`) — `ping` et connexion TCP échouent avec "No route to host", alors que
`docs/network.md` indique que les deux sont sur le même réseau local. À vérifier côté réseau
domestique (bail DHCP de `nzxt` peut-être changé, VLAN, ou pare-feu Windows) — l'intégration
Sunshine fonctionne correctement une fois la bonne adresse joignable configurée dans les réglages
`sunshine.server_url`.
