# v0.22.1 — Akasha Aura : onglet Jeux + bouton Paramètres

> Complète les 3 onglets principaux d'Akasha Aura avec des tuiles **Jeux** et un accès direct
> **Paramètres** depuis le bandeau supérieur.

## Ce qui est livré

- **Bouton Paramètres** (id `3200`) en haut à droite du bandeau, ouvrant `ActivateWindow(Settings)`.
- **`resources/lib/games_shortcuts.py`** : parsing de `games.DATA.xml` en module pur, testable.
- **Onglet Jeux** : 3 tuiles cliquables (`2010`-`2012`) issues de `skin-patches/shortcuts/games.DATA.xml` :
  - **Steam Link** → `RunAddon(plugin.program.steamlink)`
  - **Moonlight** → `RunAddon(plugin.program.moonlight-qt)`
  - **Cloud Gaming** → `RunAddon(script.cloud.gaming)`
- **Onglet App** reste en placeholder (jalon 5/6 à venir).
- **Corrections** : `install.sh` copie `games.DATA.xml` dans
  `script.akasha.aura/resources/data/` pour que `games_shortcuts.py` le trouve à runtime.

## Validation réelle

Validation effectuée le 2026-08-18 via PixelCamera (`http://localhost:8088/frame.jpg`) +
`kodi-send` sur le Pi (`192.168.1.88`) :

- Déploiement v0.22.1 → marqueur `0.22.1` confirmé sur le menu contextuel.
- Aura s'ouvre automatiquement, les rangées Divertissement s'affichent.
- Navigation `Right` jusqu'à **Jeux** : les 3 tuiles s'affichent correctement.
- Le bandeau supérieur contient bien les 5 boutons : Divertissement, Jeux, App, Bibliothèque,
  Paramètres.

## Notes

- Le lancement effectif d'un jeu (Steam Link / Moonlight / Cloud Gaming) n'a pas été testé en
  profondeur ; il délègue au `RunAddon` défini dans le shortcut, qui est le même mécanisme déjà
  utilisé par le menu Jeux natif.
- Prochain jalon : **App** (inventaire des addons installés + Akasha Store).

(manifeste JSON des addons Akasha) — voir `docs/aura/roadmap.md`.
