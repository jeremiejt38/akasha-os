# v0.23.0 → v0.23.3 — Akasha Aura, jalon 5 : onglet App (inventaire des addons)

> Jalon 5 de la roadmap `docs/aura/roadmap.md` : lister les addons "app-like" installés (scripts,
> plugins), avec épinglage, lancement et désinstallation, complétant les 3 onglets principaux
> d'Akasha Aura.

## Ce qui est livré

- **`resources/lib/addons_inventory.py`** : module pur (sans dépendance `xbmc*`) qui :
  - construit la requête JSON-RPC `Addons.GetAddons` ;
  - parse la réponse en filtrant sur les types "app-like" (`xbmc.python.script`,
    `xbmc.python.pluginsource`) et en excluant les addons Akasha eux-mêmes ainsi que les addons
    système (`service.*`, `virtual.*`, `script.skinvariables`, `script.texturemaker`) ;
  - gère la persistance des addons épinglés (parse/serialize/toggle d'une liste d'ids) ;
  - trie la liste (épinglés d'abord, puis alphabétique).
- **`resources/lib/aura_app.py`** : `WindowXMLDialog` listant les addons, avec 3 actions :
  - **Lancer** → `RunAddon(<addonid>)`
  - **Epingler / Desepingler** → bascule + persistance dans le setting `app.pinned`
  - **Desinstaller** → délégation à la fenêtre native `AddonInformation`
    (`ActivateWindow(AddonInformation,<addonid>,return)`), conformément à `docs/aura/decisions.md`
    (pas de méthode JSON-RPC publique de désinstallation).
- **`resources/skins/Default/1080i/AuraApp.xml`** : interface de l'inventaire (liste + barre
  d'outils Lancer/Epingler/Desinstaller/Retour).
- **Onglet App dans `Aura.xml`** : jusqu'à 4 tuiles d'applications épinglées + un bouton
  "Gerer les applications" ouvrant `AuraApp.xml`.
- **Bouton Paramètres** (`v0.22.1`) et **navigation Down** des onglets Jeux/App vers leurs tuiles
  (corrigée en `v0.23.1`, elle pointait vers un bouton caché).
- **`tests/test_addons_inventory.py`** : 9 tests unitaires (filtrage, exclusions, persistance,
  tri).

## Corrections apportées pendant la validation (v0.23.1 → v0.23.3)

1. **v0.23.1** : `ondown` des boutons d'onglets Jeux/App pointait vers un bouton caché (`9000`),
   empêchant d'atteindre les tuiles avec la télécommande. Corrigé pour pointer directement vers la
   première tuile de chaque onglet.
2. **v0.23.2** : la requête JSON-RPC `Addons.GetAddons` demandait la propriété `type`, qui est
   toujours renvoyée automatiquement et n'est pas un champ valide pour le paramètre `properties`
   — Kodi rejetait toute la requête (`Invalid params`).
3. **v0.23.3** : la requête demandait aussi `icon`, qui n'existe pas — le champ s'appelle
   `thumbnail` dans l'API JSON-RPC de Kodi. Même symptôme (requête rejetée, 0 app affichée).

## Validation réelle

Validée le 2026-08-18 via PixelCamera + `kodi-send` sur le Pi (`192.168.1.88`), en v0.23.3 :

- Navigation `Right` → onglet App, `Down` → tuiles/bouton "Gerer les applications" : fonctionnelle.
- Ouverture de l'inventaire : **9 applications** listées (Cloud Gaming, Jellyfin, Moonlight,
  PM4K for Plex, Steamlink, TMDb Helper, TubeCast, YouTube, YTMusic) — les addons système et
  Akasha eux-mêmes sont bien exclus.
- Épinglage de "Cloud Gaming" : persistance confirmée dans
  `script.akasha.aura/settings.xml` (`app.pinned=script.cloud.gaming`) et affichage immédiat de la
  tuile "Cloud Gaming" dans l'onglet App après fermeture du dialogue.
- Action "Desinstaller" non testée en conditions réelles (délégation à la fenêtre native, jugée
  suffisamment sûre par construction — pas de manipulation directe du système de fichiers).

## Notes

- La navigation clavier/télécommande à l'intérieur de la liste suit le comportement standard
  Kodi : `Up` depuis un élément qui n'est pas en haut de liste déplace la sélection dans la liste ;
  ce n'est qu'une fois en haut de liste qu'`Up` supplémentaire sort vers la barre d'outils.
- Prochain jalon possible (non planifié à ce stade) : **Akasha Store** (jalon 6, manifeste
  d'addons prédéfinis installables depuis Aura).

## Pour reprendre ce chantier dans une autre conversation

Les 3 onglets d'Akasha Aura (Divertissement, Jeux, App) sont désormais **tous fonctionnels et
validés sur le device**, avec en plus la Bibliothèque complète et le bouton Paramètres. Le
chantier "3 onglets" annoncé par l'utilisateur est donc terminé. Le jalon 6 (Akasha Store) reste
optionnel et non planifié.
