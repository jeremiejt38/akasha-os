# v0.24.0 → v0.24.1 — Akasha Aura, jalon 6 : Akasha Store

> Jalon 6 (dernier jalon prévu par `docs/aura/spec.md`) de la roadmap `docs/aura/roadmap.md` :
> un manifeste JSON curaté d'addons/dépôts déjà validés pour Akasha OS, installables en un geste
> depuis Aura, complétant l'onglet **App**.

## Ce qui est livré

- **`resources/data/store_manifest.json`** : manifeste JSON curaté de 7 addons de streaming/replay
  déjà disponibles dans les dépôts Kodi par défaut (vérifié en direct sur le device via
  `Addons.GetAddons(installed=false)`) : france.tv, Arte +7, Arte Mediathek, RadioFrance, Twitch,
  Vimeo, SoundCloud.
- **`resources/lib/store_manifest.py`** : module pur (sans dépendance `xbmc*`) qui charge le
  manifeste et annote chaque entrée d'un statut `installed` (comparé à la liste des addons
  installés sur le device).
- **`resources/lib/aura_store.py`** : `WindowXMLDialog` listant le manifeste, avec une action
  **Installer** déléguée au builtin natif `InstallAddon(<addonid>)` — pas de manipulation directe
  du système de fichiers, cohérent avec la politique de `docs/aura/decisions.md`.
- **Bouton "Akasha Store"** ajouté dans `AuraApp.xml`/`aura_app.py`, ouvrant le Store et
  rafraîchissant l'inventaire "App" au retour.
- **`tests/test_store_manifest.py`** : 5 tests unitaires (parsing, entrées invalides, statut
  installé).
- **v0.24.1** : exclut `script.module.inputstreamhelper` (dépendance technique, pas une
  "application") de l'inventaire App.

## Validation réelle

Validée le 2026-08-18 via PixelCamera + `kodi-send` sur le Pi (`192.168.1.88`), en v0.24.0/v0.24.1 :

- Navigation App → Akasha Store : les 7 addons du manifeste s'affichent, tous "Non installe" au
  premier essai (cohérent avec l'état réel du device).
- Sélection de "france.tv" + action Installer : `InstallAddon(plugin.video.francetv)` déclenche
  une boîte de dialogue de confirmation native Kodi (`DialogConfirm.xml`), confirmée avec
  `Select` → installation réussie, confirmée dans les logs Kodi
  (`CAddonMgr::FindAddon: plugin.video.francetv v2.0.4+matrix.1 installed`) et par la présence du
  dossier `/storage/.kodi/addons/plugin.video.francetv`.
- Retour à l'inventaire App : le nombre d'applications passe de 9 à 11 (france.tv +
  InputStream Helper, une dépendance installée automatiquement), confirmant que les addons
  installés depuis le Store apparaissent bien dans la liste App comme prévu par la spec.
- Correctif v0.24.1 (InputStream Helper exclu) validé au redéploiement suivant.

## Notes

- Le manifeste est un fichier JSON versionné dans le dépôt (`resources/data/store_manifest.json`),
  facile à étendre : ajouter une entrée `{"addonid": "...", "name": "...", "summary": "..."}`.
- Chaque entrée doit correspondre à un addon réellement résolvable par les dépôts déjà activés sur
  le device (vérifié ici pour repository.xbmc.org) ; sinon `InstallAddon` échoue silencieusement.
- Ce jalon clôt la spec initiale d'Akasha Aura (`docs/aura/spec.md`) : les 3 onglets et leurs
  sous-fonctionnalités (rangées Plex, bibliothèque complète, tuiles Jeux, inventaire App, Akasha
  Store) sont tous implémentés et validés sur le device réel.
